# 本地 AI：安装、使用与边界

职航支持 Ollama 本机服务，不需要购买模型 API 或填写 API 密钥。模型只负责岗位分析、选择已确认经历、提示证据缺口与面试练习；职位发现、薪资待遇、截止时间和真实投递入口仍由官网读取或搜索服务提供。

本轮推荐 **Qwen3.5-4B作为默认分析模型，Qwen3.5-2B作为速度优先备选**。两者已经在验收电脑实际安装。4B在本次两组职业分析样例中表现更完整；2B存在把Pandas混称为SQL工具的问题。此结论只针对本次样例和机器，不代表通用模型排行榜。

## 已核对的候选

2026-11-11 查询官方模型卡与 Ollama 模型库。下表是 Windows llama.cpp 版本的下载体积，不能直接当作实际运行内存或速度。

| 候选 | 下载体积 / 量化 | 选择依据 |
|---|---|---|
| [Qwen3.5-2B](https://ollama.com/library/qwen3.5:2b) | 约2.7GB，语言模型Q8_0 | 小体积，优先测试轻量中文分析 |
| [Qwen3.5-4B](https://ollama.com/library/qwen3.5:4b) | 约3.3GB，语言模型Q4_K_M | 作为质量对比候选，需要本机测量响应与内存 |
| [Gemma4-E2B](https://ollama.com/library/gemma4:e2b) | 约4.6GB，Q4_K_M | 官方包包含多模态与辅助组件，整体更大；本轮没有下载实测 |

模型名称中的“2B”或“E2B”不能替代整个分发包的内存测量。Qwen3.5-2B 的 [官方模型卡](https://huggingface.co/Qwen/Qwen3.5-2B) 标明 Apache 2.0 许可；模型及运行器按各自许可分发，未包含在本项目的MIT许可或源码包内。本轮不开启模型长思考，官方模型卡也提示2B思考模式可能出现循环。

## 本机接入

1. 安装 [Ollama 官方 Windows 发行版](https://docs.ollama.com/windows)，或使用同页说明的独立CLI。正常安装后执行 `ollama pull qwen3.5:4b` 下载默认模型；需要速度备选时再下载 `qwen3.5:2b`。
2. 确认服务仅监听 `http://127.0.0.1:11434`，执行 `ollama serve` 或启动已安装的 Ollama。不要把它直接暴露到公网。
3. 在职航“API与邮箱 → AI分析助手”选择“本地AI · Ollama”，填写已下载模型名，点击“测试模型连接”。本地模式没有API密钥字段。
4. 先建立并确认真实经历，再打开具体岗位的“AI匹配建议”。可查看建议、回到原文核对，或按建议选择事实生成简历。生成文件仍使用已确认经历原文，不把模型自由生成的内容直接写成个人事实。

在“模型名称”改为 `qwen3.5:2b` 并保存即可切换备选；改回 `qwen3.5:4b` 恢复默认。运行时只加载其中一个，不同时占用两份模型内存。

## 本机测量

验收环境：Windows、Ryzen 5 7530U（6核12线程）、约31.3GiB物理内存、无独立显卡；安装前约6.3GiB可用。保持用户其他应用运行，未关闭其他工作。线程数限制为4，CPU推理。

| 模型 | 两次最终样例分析耗时 | 输出速度 | 加载后的进程工作集快照 |
|---|---|---|---|
| Qwen3.5-2B Q8_0 | 18.76秒 / 24.66秒 | 约7.8—8.2 tokens/s | 约2.8GiB |
| Qwen3.5-4B Q4_K_M | 34.48秒 / 28.77秒 | 约4.4—5.3 tokens/s | 约3.6GiB |

上表为真实测量，不是独占空闲电脑的严格性能实验；其他应用负载、首次加载、输入长度都会影响速度。早期短提示的2B测试约8秒，不能替代最终更严格提示的18—25秒结果。4B适合等待几十秒的轻量求职分析，不应称为秒级高并发聊天服务。这里只验证文本分析，未验证图片识别能力。

安装器：Ollama v0.40.16 官方独立Windows包，SHA256 `50fcf5ad54277f2fa5d173ebfc93bcb017adbc0c9ef2314daabc96ca9e6aa64e`。模型清单摘要：2B `0689d44085e06d165161a8a9a1731344278cfb5aade63a3c3dbdb48ab54b130a`；4B `d8b0f5e9760cd1682034f292d7ef72ec46f432149be0df7574bf2d6e92e38c04`。模型下载由Ollama验证内容散列，后续标签更新可能对应不同文件。

本项目的Windows便携启动脚本读取用户文档目录中的 `LocalAI/installation.json`。该文件由本机安装过程生成，包含 `binary` 与 `models` 的绝对路径，不随源码公开。正常Ollama安装用户可以直接启动其官方应用，职航不依赖此文件。

已配置便携版时，“启动职航.cmd”会同时检查并启动本地AI；也可单独使用“启动本地AI.cmd”和“停止本地AI.cmd”。没有添加系统开机自启动，也未修改系统PATH。停止职航不会删除模型或账号数据；空闲模型在约2分钟后释放，轻量服务进程仍可保留。

## 资源设置与数据流

- CPU模式，4个计算线程、4096上下文、一次只处理一个分析请求；默认模型空闲2分钟卸载。
- 本地助手只取岗位前1000字、关联度最高的最多5项已确认经历，每项最多200字，并在结果中显示范围。长JD必须回原文核对，不能把摘要当完整资格审核。
- 请求只到固定回环地址；拒绝自定义内网地址、跳转、云端模型别名和未下载模型。公共职位抓取仍执行原有公网地址校验。
- 便携启动设置 `OLLAMA_NO_CLOUD=1`，不把本地请求转给云端。用户另选云端模式时遵循对应服务的数据处理条件。
- 结构化输出约束字段，后端再次过滤不存在和未确认的事实ID。它减少格式错误，不保证模型每条建议都正确，也不是完整提示注入防御的证明。
- 不用模型执行命令、访问邮箱或自动调用网页工具。申请发送仍受独立的收件地址、事实状态和用户授权检查。
