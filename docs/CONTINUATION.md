# 维护与续接

项目根是独立的`careerflow`目录，父目录为个人简历/PPT材料，不应整树发布。公开仓库仅包含本项目审查过的源码、虚构演示和公共短摘要；真实用户档案、简历、邮箱凭据、运行数据库和详细采集内容都在Git排除范围。

2026-11-11范围：面向所有求职者的本机试运行版，不把原用户的姓名、学校、专业、届别或就业目标写成产品默认值。用户选择自己的测试邮箱做真实收发验收；现阶段还没有真实账号配置。需沿用现有授权完成自发邮件、收到原邮件、用户回复、关联收信四步，不索取聊天中的密码或验证码。未获得真实外部回执前不能标记端到端实发通过。

运行入口：启动职航.cmd / 停止职航.cmd。默认端口8769，调度器仅随服务运行。一个数据目录只运行一个服务实例。恢复时先看任务和发送状态，发送未知不得盲目重发。不得结束其他项目的Python或浏览器进程。

下阶段优先补足：真实邮箱与模型API验收；主要国内渠道的合法账号/合作适配与各自独立验收；更完整的企业信息和入职时间约束；公众服务的身份恢复、数据导出/删除、出站隔离、队列与备份。需要登录的平台继续给真实申请入口让用户处理，不绕过认证。产品范围不等于已取得平台接口权限。
